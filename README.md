# TEAM-CYB

نسخه اولیه یک پیام‌رسان مستقل Flutter.

## اجرا
```bash
flutter pub get
flutter run
```

## ساخت APK
```bash
flutter build apk --release
```

این نسخه prototype است و پیام‌رسانی واقعی، سرور، احراز هویت، دیتابیس، تماس و پرداخت در مراحل بعدی باید به backend واقعی متصل شوند.

هیچ کد یا asset اختصاصی Telegram، Rubika یا Soroush Plus در این پروژه استفاده نشده است.
